## Box01 - MakeCode Arcade Console v2.0

Welcome to your brand-new **MakeCode Arcade Console**, a standalone portable gaming device powered by the **Raspberry Pi RP2040**. It's designed for creating, playing, and sharing retro games using the Microsoft MakeCode Arcade editor.

**Now with expanded capabilities:** The console also supports **MicroPython** and **CircuitPython**, unlocking a world of interactive projects and hardware prototyping beyond gaming.
